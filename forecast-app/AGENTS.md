# Forecast app guide (forecast-app/)

Expo / React Native (TypeScript) app that also ships as a static web build. Repo-wide rules are in the root `AGENTS.md`; this file adds the app's own.

- **Expo changes every SDK.** Before using an Expo or React Native API, read the `expo` major in `package.json` and check `https://docs.expo.dev/versions/v<major>.0.0/`. Install packages with `npx expo install <pkg>`.
- **Routes live in `src/app/`** (Expo Router). One file per screen; keep non-route code in `src/components`, `src/features`, `src/data`, `src/theme`.
- **Data goes through `src/data/source.ts`** (`ForecastSource`). Screens never import fixtures directly.
- **Records follow forecast record contract v1** (`weatherloo-forecast/contract/`): UTC timestamps, `valid_time = init_time + lead_hours`, SI units on the wire. Convert units only for display (`src/data/report.ts`).
- **Synthetic demo fixtures** in `src/data/fixtures/` are generated by `npm run fixtures`; do not hand-edit them, and clearly label their values as illustrative rather than live forecasts.
- **Validate:** `npm run typecheck && npm run build:web`.
- Never create `ios/` or `android/` by hand; configure native behaviour in `app.json`.
